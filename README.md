# Employee Data Analysis using Python

Overview:
This project analyzes employee salary and department-wise distribution using Python.
The goal is to extract meaningful insights from raw data and present them in a clear,
business-friendly format.

Tools & Technologies:
- Python
- pandas
- matplotlib

Key Analysis Performed:
- Overall average salary calculation
- Department-wise average salary analysis
- Employee count per department
- Visual representation using bar charts

Key Insights:
- Department 2 has the highest average salary, indicating higher cost allocation.
- Department 1 has fewer employees compared to other departments.
- Salary distribution shows concentration in specific departments.

Outcome:
This analysis demonstrates how Python can be used to transform raw organizational data
into actionable insights for decision-making.
